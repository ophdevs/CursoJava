# LeetCode Solutions

Soluções de problemas do LeetCode escritas em Java.

## Estrutura

```
leetcode/
├── easy/       # Problemas fáceis
├── medium/     # Problemas médios
└── hard/       # Problemas difíceis
```

## Convenção de nomes

Cada arquivo segue o padrão: `<número>_<nome-do-problema>.java`

Exemplo: `1_TwoSum.java`
